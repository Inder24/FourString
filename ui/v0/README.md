# FourString UI · version 0

Baseline screenshots of the playable app and each top-level tab, captured after the full-arrangement overview and gentle tempo-variation update. Practice sub-tabs and Hedwig’s Theme are included so the learning flow is visible too.

Desktop captures use a 1440 × 900 viewport; mobile captures use Pixel 7 dimensions. Images show local UI states, not microphone recordings or API responses. Hedwig’s Theme is a short opening study, not the complete original composition.

Regenerate against a running local app with `node scripts/capture-ui.mjs <local-url>`.
