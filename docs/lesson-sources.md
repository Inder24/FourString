# Lesson sources and provenance

Checked 12 September 2026. “Source-backed” means that the linked teaching material supports the specific chord, tuning, rhythm, tempo, or melody context named here. It is not an endorsement, review, or approval of the Four Strings arrangement.

All practice scores use standard high-G ukulele tuning: G4, C4, E4, A4. The downloadable JSON is generated from the same line and chapter data used by the lesson player and contains expanded note/chord events with beats, frets, string indices, and MIDI pitches. Four Strings validates fret, string, beat, duration, and MIDI ranges before download.

## Source-backed studies

### Twinkle Twinkle

- Type: melody
- Key: C
- Arrangement: Four Strings beginner melody v1.0
- [3 Easy Songs You Can Fingerpick on Ukulele Today](https://ukuleletricks.com/ukulele-fingerpicking-nursery-rhymes/) supports teaching “Twinkle, Twinkle Little Star” as an accessible solo fingerpicking piece with a simple quarter-note rhythm and frequent open strings.
- [Lesson 2: Master Smooth Chord Changes](https://ukuleletricks.com/learn-to-play-ukulele/lesson-2-master-smooth-chord-changes/) supports the standard C, F, and G7 shapes and uses them in a beginner Twinkle chord-change lesson.
- Limitation: the exact Four Strings string/fret path and chord-bed treatment are our beginner arrangement. The sources do not certify it.

### Yellow

- Type: accompaniment
- Key: C
- Arrangement: Four Strings lyric-free chord study v1.0
- [Yellow by Coldplay — Ukulele Chords & Tabs](https://ukutabs.com/c/coldplay/yellow/) supports a rookie gCEA interpretation in C, the C–G–F verse movement, F–Am–G chorus movement, island strum, and an approximately 87 BPM practice tempo.
- Limitation: this is a lyric-free chord study, not the original recording or melody. UkuTabs describes a contributor interpretation; it does not endorse the Four Strings study.

### I’m Yours

- Type: accompaniment
- Key: C
- Arrangement: Four Strings lyric-free chord study v1.0
- [I’m Yours — Ukulele Chords and Tutorial](https://acousticbridge.com/im-yours-ukulele-chords/) supports the beginner transposition to C and the repeating C–G–Am–F progression. It also notes that the original recording does not feature ukulele.
- [I’m Yours Ukulele Tutorial — Jason Mraz](https://raysukulele.com/ukulele-tutorials/im-yours-jason-mraz/) supports standard GCEA tuning, the C–G–Am–F progression, and the D–D-U–U-D-U island strum.
- Limitation: this is a lyric-free chord study, not the original recording or melody. Neither tutorial endorses or reviews the Four Strings study.

## Data-safety boundary

Only absolute HTTPS source URLs are accepted for source-backed status and rendered as external links. A lesson declared source-backed is treated as unverified if its type, tuning, key, arrangement version, source title, source scope, or URL is missing or invalid. Source-backed and original lessons can be practised; unverified lessons remain blocked.
